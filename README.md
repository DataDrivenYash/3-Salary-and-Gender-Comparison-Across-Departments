🚀 Gender-Based Employee Insights Dashboard (1999–2002)
Data + Storytelling = 🔥
I successfully wrapped up a hands-on project demonstrating how to integrate MySQL with Tableau to extract real business insights!
Using the employees_mof dataset, I built a dynamic dashboard featuring 4 insightful visualizations that answer key gender-based questions in the workplace.

📊 Business Questions Answered
1️⃣ Yearly breakdown of male vs female employees since 1990
2️⃣ Comparison of male vs female managers across departments by year
3️⃣ Average salary comparison between male and female employees (up to 2002) with department-level filtering
4️⃣ Stored procedure to calculate average male and female salaries per department within a user-defined salary range

💡 Workflow Highlights
✅ Used MySQL Workbench to write queries and create a stored procedure

✅ Exported cleaned results to CSV

✅ Built interactive visualizations using Tableau Public

✅ Pre-processed data efficiently in MySQL to optimize performance in Tableau

🗃 Dataset Information
Name: employees_mof
Description: Contains employee records from 1999 to 2002, including gender, job roles, departments (customer service, finance, HR, marketing, production, quality management, research, sales, development), and salary details.

📈 What I Learned
This project reinforced the importance of structuring and cleaning data in MySQL before visualization. By combining strong database skills with Tableau’s visual storytelling, I was able to deliver a clear and compelling narrative from raw data.
